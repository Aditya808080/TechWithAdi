Ubuntu 24.04 पर Docker Installation कैसे करें? (Complete Hindi Guide)

Docker आज की सबसे लोकप्रिय containerization technology है। इसकी मदद से applications को आसानी से deploy, manage और scale किया जा सकता है। इस guide में हम Ubuntu 24.04 पर Docker install करना सीखेंगे।

Docker क्या है?

Docker एक platform है जो applications और उनकी dependencies को containers में run करने की सुविधा देता है। इससे development और production environment में consistency बनी रहती है।

Step 1: System Update करें

sudo apt update
sudo apt upgrade -y

Step 2: Required Packages Install करें

sudo apt install apt-transport-https ca-certificates curl software-properties-common -y

Step 3: Docker GPG Key Add करें

curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker.gpg

Step 4: Docker Repository Add करें

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list

Step 5: Docker Install करें

sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io -y

Step 6: Installation Verify करें

docker --version

Step 7: Docker Service Status Check करें

sudo systemctl status docker

Hello World Test

sudo docker run hello-world
यदि Hello World message दिखाई देता है, तो Docker successfully install हो चुका है।

Useful Docker Commands

docker ps
docker ps -a
docker images
docker stop container_id
docker rm container_id

Common Errors

Permission Denied:

sudo usermod -aG docker $USER

Docker Service Not Running:

sudo systemctl restart docker

Top 25 Networking Interview Questions

English

Q1. What is IP Address?

Unique address used to identify a device on a network.

Q2. What is Subnet Mask?

Used to divide networks into subnets.

Q3. What is Gateway?

Device that routes traffic to other networks.

Q4. What is DNS?

Converts domain names into IP addresses.

Q5. What is DHCP?

Automatically assigns IP addresses.

Q6. Difference between Hub and Switch?

Switch is intelligent; hub broadcasts to all ports.

Q7. What is Router?

Connects multiple networks.

Q8. What is NAT?

Translates private IPs to public IPs.

Q9. What is OSI Model?

7-layer networking model.

Q10. What is TCP?

Reliable connection-oriented protocol.

Q11. What is UDP?

Fast connectionless protocol.

Q12. What is Port Number?

Logical communication endpoint.

Q13. What is VLAN?

Logical network segmentation.

Q14. What is MAC Address?

Hardware address of a network interface.

Q15. What is ARP?

Maps IP addresses to MAC addresses.

Q16. What is ICMP?

Used for diagnostics like ping.

Q17. What is Ping?

Tests connectivity.

Q18. What is Traceroute?

Shows network path.

Q19. What is Firewall?

Filters network traffic.

Q20. What is VPN?

Creates secure encrypted tunnel.

Q21. What is Bandwidth?

Maximum data transfer capacity.

Q22. What is Latency?

Delay in network communication.

Q23. What is Load Balancer?

Distributes traffic.

Q24. Difference between HTTP and HTTPS?

HTTPS is encrypted.

Q25. Explain Networking Troubleshooting.

Check IP, DNS, gateway, ping, routes and logs.

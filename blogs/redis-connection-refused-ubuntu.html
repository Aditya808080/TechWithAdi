Ubuntu में Redis Connection Refused Error को कैसे Fix करें? (100% Working Guide)

अगर आप Ubuntu Server पर Redis इस्तेमाल कर रहे हैं और आपको यह error दिखाई दे रही है:

Could not connect to Redis at 127.0.0.1:6379: Connection refused

यह Redis की सबसे common problems में से एक है।

Step 1: Redis Service Status Check करें

sudo systemctl status redis-server

Step 2: Redis Restart करें

sudo systemctl restart redis-server

Step 3: Port Check करें

sudo ss -tulnp | grep 6379

Step 4: Logs Check करें

sudo journalctl -u redis-server -n 50

Step 5: Configuration Verify करें

bind 127.0.0.1
port 6379
protected-mode yes

Step 6: Firewall Check करें

sudo ufw status

Step 7: Connectivity Test करें

redis-cli ping

Expected Output:

PONG

निष्कर्ष

Redis Connection Refused Error आमतौर पर Service Failure, Configuration Issue या Port Binding Problem की वजह से आती है.

Top 30 Linux Interview Questions

Q1. What is Linux?

Linux is an open-source Unix-like operating system.

Q2. What is Kernel?

Kernel is the core of the OS that manages hardware and processes.

Q3. What is a Linux Distribution?

A distribution bundles Linux kernel with tools and packages.

Q4. What is root user?

Root has full administrative privileges.

Q5. What is pwd?

Displays current working directory.

Q6. What is ls?

Lists files and directories.

Q7. Difference between hard and soft link?

Hard links point to inode; soft links point to path.

Q8. What is inode?

Stores file metadata.

Q9. How to check disk usage?

Use df -h and du -sh.

Q10. How to check memory usage?

Use free -h.

Q11. What is grep?

Searches text patterns.

Q12. What is find command?

Finds files and directories.

Q13. What is chmod?

Changes permissions.

Q14. What is chown?

Changes ownership.

Q15. How to check processes?

Use ps, top, htop.

Q16. What is systemd?

Modern Linux init system.

Q17. What is systemctl?

Manages services.

Q18. What is SSH?

Secure remote login protocol.

Q19. What is Cron?

Schedules tasks.

Q20. What is DNS?

Resolves names to IP addresses.

Q21. What is NFS?

Network file sharing service.

Q22. What is RAID?

Combines disks for redundancy/performance.

Q23. What is LVM?

Flexible logical storage management.

Q24. Difference between RAID and LVM?

RAID focuses on disks; LVM on volume management.

Q25. How to check open ports?

Use ss -tulnp.

Q26. What is Docker?

Containerization platform.

Q27. What is Apache?

Popular web server.

Q28. How to view logs?

Use journalctl and tail.

Q29. Linux boot process?

BIOS/UEFI → GRUB → Kernel → systemd.

Q30. Top Linux interview tip?

Practice troubleshooting and commands daily.
